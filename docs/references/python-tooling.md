# python-tooling：Python 标准库

- 类型：官方文档。
- 适用范围：模板脚本使用的 Python 3.11+ 标准库 API。
- 基线版本：Python 3.11；在更高版本上运行时也应确认差异。
- 官方入口：https://docs.python.org/3.11/
- 重点章节：
  - pathlib：https://docs.python.org/3.11/library/pathlib.html
  - subprocess：https://docs.python.org/3.11/library/subprocess.html
  - unittest：https://docs.python.org/3.11/library/unittest.html
  - argparse：https://docs.python.org/3.11/library/argparse.html
- 使用目的：核对跨平台路径处理、子进程调用、测试和 CLI 行为。
- 非目标：据此认定业务项目也必须使用 Python。
- 阅读状态：此清单仅登记来源，尚未在本模板交付过程中在线核对。
- 复用限制：默认只核对 API；如需复制文档或代码，另行核实适用许可。
